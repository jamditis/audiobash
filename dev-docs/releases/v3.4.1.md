# AudioBash v3.4.1 release evidence

Status: Local security candidate. Public release and Store submission are pending.

This candidate updates Electron from 43.4.1 to 43.8.3 and the build toolchain
to Node 22.23.4 with npm 10.9.9. The public download version stays at 3.4.0
until reviewed release artifacts are available.

## Security coverage

Electron 43.8.3 carries the October certificate SPKI blocklist changes for
Chromium and Node, together with the current Electron 43 Chromium fixes.
It still embeds Node 24.22.0. The upstream change to Node 24.22.1 is open at
https://github.com/electron/electron/pull/55161 as of October 21, 2026.

This candidate must not be described as fixing every issue in the October
Node advisory. Verify an official Electron release containing Node 24.22.1
or equivalent backports before closing that part of the security update.

Sources:

- https://nodejs.org/en/blog/vulnerability/october-2026-security-releases
- https://github.com/electron/electron/releases/tag/v43.8.3
- https://github.com/electron/electron/blob/v43.8.3/patches/node/tls_reject_chains_containing_blocked_public_keys.patch

## Validation

The baseline focused source gate passed 74 of 75 checks. Its remaining failure
was the exact toolchain check because the verified local Node 22.23.4 and npm
10.9.9 were newer than the old project pins.

The updated focused contract checks pass (48 tests). Prettier, TypeScript,
the renderer build, and ESLint pass; ESLint retains 33 existing warnings.

The Linux source suite passed 999 tests and skipped 36. One lint-budget test
initially failed because the exported validation tree lacked a Git index.
With that validation prerequisite present, all four lint-budget tests pass.
The full Windows source suite still has failures in unchanged POSIX fixture
and process-launch checks. The Windows process-tree suite passes all seven
checks in isolation after the native builds finished; an earlier run under
build load hit its existing deadline. No test deadlines or assertions were
relaxed.

Both test-identity and production-identity Windows AppX candidates build,
unpack, and pass identity verification and the packaged process/PTY probe.
These artifacts were built from source commit
`59e3ce3ab115bf5edf87bef9e862f3187a4b3738`; subsequent changes only record
this evidence. The source diff received independent review with no
actionable findings. Signed public artifacts, macOS validation, Store
submission, and the complete upstream Node fix remain pending.

The machine-wide Node MSI update was rejected by automatic approval policy.
Local validation uses the official Node 22.23.4 ZIP, checked against the
published SHA-256 and a valid OpenJS Foundation Authenticode signature.
