# AudioBash v3.4.0 release evidence

Status: Work in progress.

This document records the evidence used to prepare AudioBash v3.4.0. It does not contain passwords, private keys, API key identifiers, issuer identifiers, or certificate archives.

## Release goal

Ship smaller and more stable macOS arm64 and x64 packages. Both packages must use a supported Electron release, pass the test and static-analysis gates, carry a Developer ID signature with a secure timestamp, pass Apple notarization, include a stapled ticket, and pass Gatekeeper checks before publication.

## Task 3 package isolation evidence

Vite keeps renderer output in `dist`. Electron-builder now writes package output to ignored `release`. The mac target list contains only `dmg` and `zip`; arm64 and x64 selection comes from separate scripts that always use `--publish never`. The combined mac script runs the two architecture scripts in sequence.

The mac artifact pattern is `${productName}-${version}-${arch}.${ext}`. The explicit package gate reads the product name and current version from `package.json`. It fails when either architecture's app, executable node-pty helper, DMG, or zip is absent. Normal `npm test` excludes this package-only suite.
