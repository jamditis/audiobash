# AudioBash v3.4.0 release evidence

Status: Work in progress.

This document records the evidence used to prepare AudioBash v3.4.0. It does not contain passwords, private keys, API key identifiers, issuer identifiers, or certificate archives.

## Release goal

Ship smaller and more stable macOS arm64 and x64 packages. Both packages must use a supported Electron release, pass the test and static-analysis gates, carry a Developer ID signature with a secure timestamp, pass Apple notarization, include a stapled ticket, and pass Gatekeeper checks before publication.

## Release-gate evidence

| Check | Result | Evidence |
| --- | --- | --- |
| Apple Developer Program membership | Pass | The signed-in account and Apple notarization service accepted the dedicated team credential. |
| Developer ID private key | Pass | A local timestamped hardened-runtime signing probe passed. |
| Developer ID certificate | Pass | The certificate expires on February 1, 2027. |
| Issuing certificate chain | Pass | The current certificate uses Apple Developer ID G1. The G1 intermediate is installed and trusted. |
| Future certificate renewal | Pending before February 1, 2027 | A replacement certificate must use the current Apple intermediate. Apple Developer ID G2 is not required for the current G1 certificate. |
| Notarization credential | Pass | A dedicated Developer-role App Store Connect team API key passed `xcrun notarytool history`. |
| CI signing secrets | Pass | GitHub Actions lists `CSC_LINK` and `CSC_KEY_PASSWORD`. Values cannot be read back. |
| CI notarization secrets | Pass | GitHub Actions lists `APPLE_API_KEY`, `APPLE_API_KEY_ID`, `APPLE_API_ISSUER`, and `APPLE_TEAM_ID`. Values cannot be read back. |
| Temporary credential files | Blocking: pending user approval | The exact owner-only holding directory contains recoverable private-key exports and signing probes. Permanent removal needs explicit user approval and must finish before release. |

The selected release method is GitHub Actions signing with an encrypted PKCS #12 archive and notarization with a dedicated App Store Connect team API key. An ad hoc-signed v3.4.0 release is not permitted.
