# AudioBash v3.0.0 implementation plan

> **For agentic workers:** REQUIRED: Use superpowers:subagent-driven-development (if subagents available) or superpowers:executing-plans to implement this plan. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fix notification chimes, rebuild pane system with tmux-style architecture, integrate with Claude Code /voice mode.

**Architecture:** Three-phase release: bug fixes first (AudioContext, window controls, zoom/resize), then binary tree pane system replacing flat layout, then voice mode detection and handoff. Each phase produces testable, committable work.

**Tech stack:** Electron 39, React 19, TypeScript, Vite 6, xterm.js, node-pty, Web Audio API, Vitest
