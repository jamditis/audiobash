# AudioBash Remote

Mobile companion PWA for AudioBash - Voice-controlled terminal.

## Setup

```bash
npm install
```

## Development

```bash
npm run dev
```

## Build

```bash
npm run build
```

## PWA Icons

Add icon files to `public/icons/` directory. Required sizes:
- 16x16, 32x32 (favicon)
- 72x72, 96x96, 128x128, 144x144, 152x152 (mobile)
- 192x192, 384x384, 512x512 (PWA)
