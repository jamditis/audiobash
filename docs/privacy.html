Privacy policy

This policy explains how the AudioBash desktop app and the audiobash.app website handle information. AudioBash is developed and maintained by Joe Amditis.

Last updated: August 31, 2026

Summary

AudioBash has no AudioBash account system, advertising, or developer-operated transcription server.

The app records microphone audio only after you start a voice-input session. It sends audio outside your device only when you select a cloud transcription provider.

AudioBash does not sell personal information. It does not use app data for advertising or marketing profiles.

Information the app processes

Microphone audio and transcripts

AudioBash requests microphone access for voice input. Manual mode records after you start recording. Voice-activity and continuous modes listen only after you start that listening session. You can stop or cancel recording from the app.

Terminal context in agent mode

Agent mode can send the selected cloud provider your operating system, shell type, current directory, last command, last error, up to 500 characters of recent terminal output, the speech transcript, custom instructions, and custom vocabulary. This context helps the provider convert speech into a terminal command. Raw mode does not send terminal context for command generation.

Terminal output and paths can contain personal, confidential, or secret information. Review what is visible in the terminal before you use agent mode.

API keys

You provide your own API keys for cloud providers. When operating-system secure storage is available, AudioBash stores these keys on your device with Electron secure storage. If secure storage is not available, the app keeps a key in memory for the current session and does not write it to disk in plain text. A key is sent only to the provider it authenticates.

Local settings and files

The app stores settings on your device. These settings can include the selected model and shell, keyboard shortcuts, custom instructions, custom vocabulary, recent and favorite directory paths, saved pane sessions, window size and position, preview settings, and local diagnostic logs. Preview screenshots are saved to the current project or the AudioBash app-data folder and copied to the clipboard. AudioBash does not upload these screenshots.

Cloud and local transcription choices

Choice Information sent
Google Gemini Recorded audio and transcription instructions. Agent mode also sends the terminal context described above.
OpenAI Recorded audio for Whisper transcription. If you use the OpenAI agent option, the transcript and terminal context are also sent for command conversion.
Anthropic Audio is first sent to OpenAI Whisper. In agent mode, the resulting transcript and terminal context are then sent to Anthropic.
ElevenLabs Recorded or streaming audio and, when applicable, custom vocabulary terms for speech recognition.
Local Whisper Audio stays on your device. The app creates temporary local audio files for processing and removes the temporary directory after the request finishes.
Local Parakeet Audio is sent to the Parakeet service that you run at localhost:8003. AudioBash does not send it to an external Parakeet server.

Cloud providers process information under their own terms and privacy policies. Review the policies for Google, OpenAI, Anthropic, and ElevenLabs. Their retention, location, and use of data can depend on your provider account and service plan.

How information is used

  • Convert speech to text or a terminal command.
  • Route the result to the terminal that you selected.
  • Save your app preferences and local workspace shortcuts.
  • Run local previews, file watching, screenshots, and saved terminal layouts.
  • Diagnose app errors with logs stored on your device.
  • Respond when you contact the developer for support.

When information is disclosed

AudioBash discloses audio, transcripts, and agent-mode context only to the cloud provider that you choose, as described above. The developer does not receive that information through an AudioBash server.

If you contact the developer by email or GitHub, your message and account or contact details are processed by the service that you use. The information is used to answer your request.

Information can also be disclosed when required by law or when needed to protect users, the public, or legal rights. AudioBash does not sell personal information or disclose it to advertising networks or data brokers.

Storage and retention

AudioBash does not keep completed microphone recordings as an app library. Cloud request data is retained by the selected provider under that provider's terms and account controls.

Settings, encrypted API keys, directory paths, saved sessions, screenshots, downloaded local models, and diagnostic logs stay on your device until you remove them, clear the related setting, or delete the AudioBash app-data folder. Main-process logs rotate after they reach their size limit and keep no more than five rotated log files.

Support messages are kept only as long as needed to answer the request, maintain a useful support record, or meet legal obligations.

Security

Cloud requests use encrypted HTTPS or secure WebSocket connections. API keys use operating-system-backed encryption when it is available. AudioBash does not persist new API keys when secure storage is unavailable.

No storage or network method can guarantee complete security. Do not speak secrets or use agent mode when terminal output contains information that you do not want to send to the selected provider.

Your controls

  • Deny or revoke microphone permission in your operating-system settings.
  • Start, stop, or cancel a voice-input session in AudioBash.
  • Select raw mode to avoid agent-mode terminal context.
  • Select Local Whisper or local Parakeet to avoid external cloud transcription.
  • Change the cloud provider or clear its API key in AudioBash settings.
  • Enable command preview and review generated commands before execution.
  • Delete screenshots, logs, local models, settings, and other app data from your device.

The default app-data locations are %APPDATA%\AudioBash\ on Windows, ~/Library/Application Support/AudioBash/ on macOS, and ~/.config/AudioBash/ on Linux. Provider-side access, correction, deletion, and retention controls are available through the provider that you selected.

Website data

audiobash.app is a static website hosted with GitHub Pages. AudioBash does not use a site account system, first-party analytics, advertising trackers, or first-party cookies.

Your browser sends normal request information, such as an IP address, user-agent string, requested page, and request time, to the hosting and content-delivery services needed to load the site. The site loads fonts from Google and code resources from Tailwind CSS and unpkg. These services handle requests under their own policies.

Children

AudioBash is a developer terminal and is not directed to children under 13. The developer does not knowingly collect personal information from children through AudioBash. A parent or guardian can contact the developer if they believe a child provided personal information through a support request.

Policy changes

This policy will be updated when AudioBash data practices change. The revised page will show a new last-updated date. A material change can also be announced in the release notes or app documentation.

Contact

For a privacy question or request, email jamditis@gmail.com. For a public bug report, use the AudioBash issue tracker. Do not put private information, API keys, or confidential terminal output in a public issue.
